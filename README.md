# نَسَق — ملفات النشر

الملفات: index.html (التطبيق) · manifest.webmanifest · sw.js · الأيقونات · privacy.html

## نشره على رابط باسمك (GitHub Pages)
1. أنشئي حسابًا على github.com باسم مستخدم: **Roaawalid** (إن كان متاحًا).
2. أنشئي مستودعًا (Repository) عامًا باسم **roaawalid.github.io**.
3. ارفعي كل ملفات هذا المجلد (Add file ← Upload files) ثم Commit.
4. من Settings ← Pages تأكدي أن المصدر هو الفرع main.
5. بعد دقائق يعمل الرابط: https://roaawalid.github.io

بديل أسهل: app.netlify.com/drop — اسحبي المجلد، ثم غيّري اسم الموقع من Site settings إلى roaawalid فيصير roaawalid.netlify.app.

## بعدها: المتاجر
- ادخلي على pwabuilder.com وأدخلي رابط موقعك ← Package for stores ← Android (ملف AAB) وiOS (مشروع Xcode).
- Google Play: حساب مطوّر (رسم مرة واحدة) ← أنشئي التطبيق ← ارفعي AAB ← الوصف من ملف store-listing.md.
- App Store: Apple Developer Program (اشتراك سنوي) + جهاز Mac مع Xcode ← افتحي المشروع ← Archive ← Upload ← App Store Connect.
